## 1. What this deploys

The hardened ASGI service in this repo (`server/app.py` on Starlette +
uvicorn, 47/47 tests green): `POST /api/pay/quote` (free),
`POST /api/pay/execute` (402-gated, 25¢ route price), `GET /health`,
`GET /healthz` (Fly check target). Docker image: `python:3.12-slim`,
non-root user, pinned deps, stdout JSON logs.

## 2. Machine size — `shared-cpu-1x`, 256 MB (in `fly.toml`)

**Why shared, why the smallest preset:** the service is a thin
JSON API — in-memory mock/CoinGecko oracle, BFS over a static graph,
integer fee math, one Ed25519 sign per execution. Idle footprint is
~60–90 MB; a single shared vCPU handles hundreds of req/s of this
workload. A dedicated CPU buys nothing until p99 latency proves
otherwise.

**Upgrade path (only if measured):** `fly scale memory 512` (OOM) or
`fly machine update --vm-cpus 2` / a second machine (latency/HA).
Start small, scale on evidence.

## 3. Region — `ewr` (Newark)

The lab is in Cherry Hill, NJ — ewr is the closest Fly region
(~90 mi), so Corey's own testing and any US-East users get the lowest
latency. Egress from ewr bills at the North America rate ($0.02/GB —
cheapest tier). Single region keeps the v1 bill trivial; multi-region
is a later call, not a default.

## 4. Monthly cost — current Fly pricing (checked 2026-09-28)

Rates (fly.io/docs/about/pricing + observed preset math):

| Resource | Rate |
|---|---|
| shared-cpu-1x, 256 MB, **running** | ≈ **$2.02/mo** (0.25 GB × $5.00/GB + 1 vCPU × $0.77; billed per-second, pro-rated) |
| Same machine, **stopped** (auto-stop) | rootfs only: $0.15/GB/mo → our ~250 MB image ≈ **$0.04/mo** |
| Outbound transfer (NA/EU) | **$0.02/GB** (inbound free) |
| Anycast IP | shared IPv4 **free** (no $2/mo dedicated IP needed) |
| Volumes | $0.15/GB/mo — **we use none** |

`fly.toml` ships with `auto_stop_machines = "stop"` /
`min_machines_running = 0` (scale to zero).

| Scenario | Math | ≈/mo |
|---|---|---|
| **Idle baseline** (auto-stop, ~0 traffic) | $0.04 rootfs + $0 egress | **~$0.05** |
| Always-on + 10k txs | $2.02 + (10k × ~3 KB ≈ 30 MB × $0.02/GB ≈ $0.001) | **~$2.03** |
| Always-on + 1M txs | $2.02 + (1M × ~3 KB ≈ 3 GB × $0.02/GB = $0.06) | **~$2.08** |
| **Per-1k-tx marginal** | 1k × ~3 KB ≈ 3 MB egress × $0.02/GB | **≈ $0.00006 → $0.00** |

Assumptions: ~1 KB request in (free), ~2 KB JSON response out. CPU per
tx is milliseconds of Python — noise next to uptime. Bottom line:
**the machine's uptime dominates, not per-tx cost**; at expected v1
traffic the app costs $0.05–$2.10/mo.

Notes: new Fly orgs are pure pay-as-you-go (credit card required, no
free allowances — check the org's billing page). Cold starts on
scale-to-zero are ~1–3 s; set `min_machines_running = 1` if that ever
matters for a demo.

## 7. Deliberately left stubbed (marked, not hidden)

- **Chamber HSM custody — TODO stays.** `AWL_RELAYER_KEY` as a Fly
  secret is the pragmatic start Corey approved 2026-09-28; the seed
  still exists as a process env var. Real custody = signing inside the
  Chamber with key_id references only. The warning block at the top of
  `server/chamber.py` still says exactly this.
- **Settlement is MOCK** — coins never move; receipts attest to the
  law that *would* execute. `AWL_MAINNET_ENABLED=1` still refuses
  loudly. Real settlement + real 402 payment verification (port from
  rider-x402) are the two big builds before mainnet.
- **/execute's 402 gate has no real rail in v1** — outside
  `AWL_TEST_MODE=1`, every unpaid request 402s. `AWL_TEST_MODE=0` is
  set in `fly.toml`, so prod 402s cleanly until a rail is wired.
- **CoinGecko is a centralized trust assumption** — documented in
  `server/oracle.py`; the `PriceOracle` ABC exists for the
  trust-minimized swap later.
- **Idempotency nonces are in-memory** — a machine stop (auto-stop /
  redeploy) resets them, so a replayed key after a cold start would be
  accepted once. Accepted for v1 scale-to-zero; v2 wants a persistent
  store before real money flows.
- **No rate limiting yet** — uvicorn serves what Fly sends. Add a
  limiter (or Fly edge / WAF) before opening the 402 endpoint to
  adversarial traffic.
